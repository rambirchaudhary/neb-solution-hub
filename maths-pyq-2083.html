Group A — Multiple Choice Questions

Attempt all questions. [11×1=11]

  1. Which one of the following represents Σn³?
    • A) n(n+1)/2
    • B) n²(n+1)/4
    • C) n²(n+1)(n+2)/4
    • D) n²(n+1)²/4
  2. Which one is the Highest Common Factor (HCF) of n!, (n+1)!, and (n+2)!?
    • A) (n+2)!
    • B) (n+1)!
    • C) n!
    • D) n
  3. Which one of the following is the equation of a circle that touches the x-axis and whose centre is at (3, 4)?
    • A) x² + y² + 6x + 8y + 9 = 0
    • B) x² + y² − 6x − 8y + 9 = 0
    • C) x² + y² + 6x + 8y + 16 = 0
    • D) x² + y² − 6x − 8y + 16 = 0
  4. In any triangle ABC, a = 3, b = 4 and c = 5, then which is equal to sin(A/2)?
    • A) 3/√10
    • B) 1/√10
    • C) 1/10
    • D) 3/10
  5. If a⃗ and b⃗ are two vectors, then the projection of vector a⃗ on b⃗ is:
    • A) (a⃗·b⃗)/|b⃗|
    • B) (a⃗·b⃗)/|a⃗|
    • C) a⃗·b⃗
    • D) (a⃗·b⃗)/(|a⃗||b⃗|)
  6. A and B are dependent events. P(A) = 1/2, P(B) = 1/3, and P(A∩B) = 1/5. Which one of the following is P(A/B)?
    • A) 1/6
    • B) 2/5
    • C) 3/5
    • D) 19/30
  7. Which one is the derivative of log(cosh(x/a))?
    • A) (1/a)tanh(x/a)
    • B) tanh(x/a)
    • C) (1/a)sech(x/a)
    • D) (1/a)coth(x/a)
  8. What is the value of limx→1 [(x³ − 1)/(x² − 1)]?
    • A) 1/2
    • B) 3/2
    • C) 2
    • D) 3
  9. Which one is the solution of y dx − (x/2) dy = 0?
    • A) y = c√x
    • B) x = c√y
    • C) y = cx
    • D) x = cy
  10. The integrating factor for the differential equation dy/dx − y/x = x² is:
    • A) log(1/x)
    • B) e−1/x
    • C) 1/x
    • D) −1/x
  11. After forward row reduction in the Gauss elimination method, if the augmented matrix of a given system of three linear equations reduces to the form a₁ b₁ c₁ : d₁ 0 b₂ c₂ : d₂ 0 0 0 : 0 then the system of equations has:
    • A) Unique solutions
    • B) Infinitely many solutions
    • C) No solutions
    • D) Only one solution
    OR
    In a projectile, the initial velocity is 40 m/s and the angle of projection is 30°. What is its time of flight?
    • A) 10/g
    • B) 20/g
    • C) 40/g
    • D) 80/g
